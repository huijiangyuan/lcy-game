# 👶 宝宝趣味游戏乐园 · Baby Fun World

专为 **1-3 岁低幼宝宝** 量身定制的沉浸式视听启蒙游戏城堡，基于 **Three.js**、**React** 与 **Web Audio API** 打造。

无论宝宝在键盘上双手拍打、双击触屏还是乱点鼠标，都有即时悦耳的声光与萌物反馈，天然和谐的五声音阶永不刺耳！

🌐 **在线体验链接**：[https://huijiangyuan.github.io/lcy-game/](https://huijiangyuan.github.io/lcy-game/)

---

## 🏰 游戏乐园大厅与三大游戏 (Game Suite)

### 🎪 乐园总入口大厅 (`index.html`)
* 绚丽灵动的糖果马卡龙视觉，配有飘浮白云动效。
* 3 大精美游戏卡片，一键直达，支持「🎲 随机挑一个玩」快速进入。
* 全局家长使用指南与全屏沉浸防跳出保护。

---

### 1. 🧸 3D 萌宠乐园 · 宝宝按按乐 (`wonder-keys.html`)
* **丰润糖果风 3D 萌物**：
  * 🐥 眨眼红脸蛋的小黄鸭、🐻 软萌小熊、🐰 长耳小白兔
  * 🎈 飘飘晃动向上飞升的彩虹气球、🍩 洒满七彩糖针的草莓甜甜圈
  * ⭐ 旋转笑脸五角星、🚗 卡通小汽车、🔤 3D 浮雕英文字母/数字认知徽章
* **5 大萌趣音效**：木琴马林巴、卡通弹簧跳跃（Boing）、咕噜噜啵啵泡泡音、仙子八音盒风铃、低音鼓咚咚声。
* **双语语音启蒙**：按字母键可爱童声报读拼音与单词（如“A 苹果 Apple”）。
* **三大场景**：🌈 糖果乐园、🌌 极光星空、🌊 萌趣深海。

---

### 2. ✨ 璀璨几何星空 · 宝宝拍拍乐 (`baby-game.html`)
* **梦幻太空与发光几何体**：深邃唯美星空、发光爱心、立体五角星、晶莹宝石、发光圆环与水晶球。
* **轻灵八音铃**：纯净高灵敏度双振荡器正弦+三角波和弦合成，清脆悠扬。
* **柔和辉光特效**：基于 UnrealBloomPass 辉光渲染与星尘粒子爆裂，护眼不刺眼。

---

### 3. 🎹 奇幻钢琴屋 · 萌趣钢琴与DJ (`piano.html`)
* **萌兔小琴师**：会随节奏欢乐摇摆的互动吉祥物。
* **三种精彩弹奏模式**：
  * 🎹 **自由弹奏**：真实彩色琴键，尽情探索音符音阶。
  * 🎵 **学习名曲**：跟随音符提示弹奏《小星星》、《两只老虎》、《欢乐颂》等经典童谣。
  * 🎧 **动感 DJ**：键盘任意乱按化身酷炫小小 DJ，触发动感电音打碟、重低音贝斯与打击乐！

---

## ✨ 核心特性

1. **⌨️ 键盘防误触与全键触发**：自动拦截浏览器翻页、返回等默认快捷键，保护宝宝拍打不跳出。
2. **🎶 悦耳防刺耳**：采用五声音阶（宫商角徵羽）与内置防爆音限幅器（Dynamics Compressor），无论宝宝怎么乱按都和谐好听。
3. **⛶ 全屏沉浸防护**：一键开启全屏，隐藏地址栏与标签页。
4. **📱 多端支持**：电脑键盘、iPad 触屏、手机触摸均能完美畅玩。
5. **🔄 随时随地跨游戏切换**：每个游戏均内置「🏠 乐园大厅」与直通其它游戏的快捷按钮。

## 🚀 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本 (自动打包所有页面与资源)
npm run build
```
