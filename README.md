# 👶 宝宝按按乐 · Baby Wonder Keys & 开心拍拍乐

专为 **1-3 岁低幼宝宝** 量身定制的 3D 沉浸式视听启蒙游戏合集，基于 **Three.js** 与 **Web Audio API** 打造。

无论宝宝在键盘上双手拍打、双击触屏还是乱点鼠标，都有即时悦耳的声光与萌物反馈，天然和谐的五声音阶永不刺耳！

---

## 🎮 内置双游戏模式 (Dual Game Modes)

本项目包含两个独立风格的高品质游戏，可通过顶部导航随时无缝切换：

### 模式一：🧸 3D 萌宠世界（宝宝按按乐 · Baby Wonder Keys）
* **丰润糖果风 3D 萌物**：
  * 🐥 眨眼红脸蛋的小黄鸭、🐻 软萌小熊、🐰 长耳小白兔
  * 🎈 飘飘晃动向上飞升的彩虹气球、🍩 洒满七彩糖针的草莓甜甜圈
  * ⭐ 旋转笑脸五角星、🚗 卡通小汽车、🔤 3D 浮雕英文字母/数字认知徽章
* **5 大萌趣音效**：木琴马林巴、卡通弹簧跳跃（Boing）、咕噜噜啵啵泡泡音、仙子八音盒风铃、低音鼓咚咚声。
* **双语语音启蒙**：按字母键报读拼音与单词（如“A 苹果 Apple”）。
* **三大场景**：🌈 糖果乐园、🌌 极光星空、🌊 萌趣深海。

### 模式二：✨ 璀璨几何星空（宝宝开心拍拍乐 · Baby Space Sparks）
* **梦幻太空与发光几何体**：深邃唯美星空、发光爱心、立体五角星、晶莹宝石、发光圆环与水晶球。
* **轻灵八音铃**：纯净高灵敏度双振荡器正弦+三角波和弦合成，清脆悠扬。
* **柔和辉光特效**：基于 UnrealBloomPass 辉光渲染与星尘粒子爆裂，护眼不刺眼。

---

## ✨ 核心特性

1. **⌨️ 键盘防误触与全键触发**：自动拦截浏览器翻页、返回等默认快捷键，保护宝宝拍打不跳出。
2. **🎶 悦耳防刺耳**：采用五声音阶（宫商角徵羽）与内置防爆音限幅器（Dynamics Compressor），无论宝宝怎么乱按都和谐好听。
3. **⛶ 全屏沉浸防护**：一键开启全屏，隐藏地址栏与标签页。
4. **📱 多端支持**：电脑键盘、iPad 触屏、手机触摸均能完美畅玩。

## 🚀 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本 (同时编译 index.html 与 baby-game.html)
npm run build
```
